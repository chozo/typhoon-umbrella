# Typhoon Umbrella

暴風雨のなか、傘を壊さずに30秒で帰宅する縦型スマホ向けWebミニゲームです。

公開URL: <https://game.chozo.net/typhoon-umbrella/>

GitHub: <https://github.com/chozo/typhoon-umbrella>

## ゲーム概要

プレイヤーは自動で自宅へ向かいます。画面を左右にドラッグして傘を左・中央・右へ傾け、横殴りの雨の方向に合わせます。

- プレイ時間は約30秒
- 画面は縦型9:16（405 × 720）
- 残り時間が `0.0` になった時点で到着・クリア
- 風と雨は5秒ごとに強くなり、後半ほど風向きの切り替えが増える
- 最後の5秒は自宅が大きく近づく演出になる

## 操作とルール

### 操作

画面を左右にドラッグして傘を傾けます。雨の方向と傘の方向は、厳密な角度ではなく次の3段階で扱います。

| 雨／傘の向き | 結果 |
| --- | --- |
| 左・中央・右が一致 | ダメージなし |
| 中央の傘で左右の雨を受ける、またはその逆 | 通常ダメージ |
| 雨と傘が左右逆 | 通常ダメージの2.4倍 |

耐久度が0になると傘が壊れてゲームオーバーです。耐久度は回復しません。

### 難易度と風

- 風向きはプレイごとに変わる滑らかなランダムパターン
- 反対方向へ短く振れてすぐ戻る「フェイント」を含む
- 5秒ごとに雨量・雨粒速度・横流れ・ダメージ倍率を強化
- 最後の5秒は過度に難しくならないよう、風向きの切り替え間隔を少し緩和
- 雨の見た目とダメージ判定は同じ風向きを基準にしている

### 演出

- 横殴りの雨は風向きに合わせて連続的に傾く
- 道路のセンターラインと建物は手前へ流れ、前進感を出す
- 人物はデフォルメした後ろ姿のイラストを使い、足を交互に上げ下げして歩く
- 傘の棒と持ち手は人物の後ろ、傘の布と骨組みは人物の前に描画する
- 耐久度低下時は傘と人物が強くバタつく
- 破損時は傘だけが裏返り、骨が飛び出して「バコォン！」と表示される

## 結果画面

### ゲームオーバー

- 見出し: `GAME OVER`
- メッセージ: `傘が壊れました`
- 壊れた赤い傘のイラストを表示
- 帰宅までに残っていた秒数を表示

### クリア

- 見出し: `HOME SWEET HOME`
- ずぶ濡れの人物イラストを表示
- コメント:

  > 無事帰れたけどずぶ濡れになった。  
  > 傘をさした意味がなかった。

どちらの結果画面にも `RETRY` と「スタート画面に戻る」を用意しています。

## 音

すべてブラウザのWeb Audio APIで合成しており、音声ファイルは使っていません。

- 雨音: 開始時は控えめで、時間経過とともに激しくなる
- 傘の破損: 短い「バコッ」という衝撃音
- クリア: インターホン風の「ピンポーン」
- BGMと風の持続音は、耳障りにならないよう削除済み

音はユーザーが `帰る` または `RETRY` を押した後に再生され、結果画面への遷移時に雨音は停止します。

## ローカルで遊ぶ

`index.html` をブラウザで開けば遊べます。音を含めて確認する場合は、ブラウザでページを開いて `帰る` を押してください。

## ビルドとデプロイ

### 必要なもの

- Node.js
- Cloudflareにログイン済みのWrangler

### コマンド

```bash
npm install
npm run build
npm run deploy
```

`npm run build` は公開対象の7ファイルを `dist/typhoon-umbrella/` に出力します。

`npm run deploy` はビルド後、Cloudflare Workers + Static Assetsへデプロイします。

### Cloudflare設定

- Worker名: `typhoon-umbrella`
- 静的アセットディレクトリ: `dist`
- ルート:
  - `game.chozo.net/typhoon-umbrella`
  - `game.chozo.net/typhoon-umbrella/*`
- `workers_dev` は無効
- Observabilityを有効化

ルート付きのStatic Assetsは、URLのパスに合わせて `dist/typhoon-umbrella/` 以下へファイルを配置する必要があります。このディレクトリ構成により、`/typhoon-umbrella/` で `index.html` を配信します。

## 作業ログ

### 企画とプロトタイプ

1. 「台風のなかを30秒で帰宅する」縦型Webミニゲームとして開始。
2. キャラクターは自動前進、プレイヤーは傘の角度だけを操作する仕様に決定。
3. 疑似3D道路・住宅街・自宅・パララックス風の背景をCanvasで実装。
4. 雨の方向、強さ、速度、横流れを風向きと連動させた。

### ゲーム性の調整

1. 濡れ度を一度実装したが、ゲーム性への寄与が小さいため完全に削除。
2. 傘の耐久度を採用し、画面上部にインジケータを追加。
3. ダメージ判定を雨と傘の3方向（左・中央・右）の一致判定へ変更。
4. 同方向は無傷、中央対横雨は通常ダメージ、左右逆は2.4倍に設定。
5. 0.0秒表示後にゲームオーバーになる問題を修正。29.95秒以降は到着扱いにしてダメージを停止。
6. 風向きはランダムかつ連続的に変わり、フェイントを含む形へ変更。
7. ラスト5秒は家が急接近する演出を追加し、最後だけ風向きの変化を少し緩和。

### ビジュアルの調整

1. 人物を単純図形から、デフォルメした後ろ姿の透明イラストへ置換。
2. 人物の頭が傘からはみ出さないよう、縮小して下寄せに調整。
3. 人物の足を左右交互に上げ下げする簡易歩行アニメーションを追加。
4. 傘はCanvas描画を維持し、レイヤーを人物の前後へ分離。
5. 破損時は人物を維持して傘だけを破壊。
6. ゲームオーバー用のリアル寄りの壊れた傘、クリア用のずぶ濡れ人物を追加。
7. ファビコンを透明背景の赤い傘、黒い輪郭と骨組みに変更。

### UIと結果画面

1. スタート画面の表記を `THPHOON UMBRELLA` に変更。
2. 結果画面からプレイ中の「あと少し！」が透けて見える問題を修正。
3. ゲームオーバーの見出しを `GAME OVER`、メッセージを「傘が壊れました」に調整。
4. クリア画面にずぶ濡れの人物と2行のオチを追加。
5. 結果画面の `HOME SWEET HOME` とクリア用イラストの位置を下へ調整。

### 音と安定性

1. Web Audio APIで雨音を追加し、時間とともに激しくなるように調整。
2. 風の音とBGMの持続音は削除し、雨音だけを残した。
3. 傘の破損音と、クリア時のインターホン風「ピンポーン」を追加。
4. 音声初期化に失敗してもゲーム自体は開始するように変更。
5. 再試行時に古いアニメーションループが残らないよう、実行IDで制御。
6. スタート画面で人物イラストの読み込み前に古い簡易人物が残る問題を修正。
